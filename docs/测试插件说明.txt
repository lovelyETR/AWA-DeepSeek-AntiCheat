================================================================================
  AWA 反作弊测试插件          Alpha v1.0
  （装在服务端的插件，不是外挂）
================================================================================

【它是干什么的】

  反作弊插件负责「抓作弊」。但你怎么确认它真的抓得住？
  平时没法验证 —— 总不能真去找个外挂来试。

  这个插件就是干这个的：它能在服务端制造出「作弊才会产生的状态」，
  然后你看反作弊能不能抓到。相当于给自己出一套模拟题。

【为什么它不是外挂】

  1. 它是服务端插件，不是客户端程序。
     玩家装不了 —— 只有服务器管理员能往服务端放 DLL。

  2. 装到你自己电脑上完全没用。
     客户端的 SCP:SL 根本不加载 EXILED 插件。

  3. 发给别人也没用。
     服务器插件必须由对方管理员主动安装、主动解锁才会运行。

  4. ★ 就算装上了，也只有管理员能用（见下面「权限管理」）。

  游戏内输入 .cl about 可以看到完整说明。


================================================================================
  权限管理（重要）
================================================================================

  ★ 只有这三类人能用，其他人一律拒绝：

      1. 服务器所有者   —— 服务端控制台，或者游戏里的主机
      2. 管理员         —— 有 RemoteAdmin 权限的人
      3. 白名单         —— 配置里点名允许的 UserID

  ★ 普通玩家、以及权限不够的人，输入任何 .cl 命令都会看到：

      你没有权限使用这个测试插件。
      它只对服务器所有者和管理员开放。

    并且服务端日志里会记一笔，能查到是谁想用。

  ★ 唯一例外：.cl about
    这只是说明文字，不执行任何注入。默认对所有人开放，
    好让别人能自己确认它不是外挂。
    想连这个也关掉：allow_about_for_everyone: false

  ── 配置项 ────────────────────────────────────────────────────────────

     # 谁能用
     allow_server_owner: true      服务器所有者（建议保持 true）
     allow_remote_admin: true      管理员（关掉就只有你自己能用）

     # 额外点名允许的玩家（适合给测试号开权限，而不用给他 RA）
     whitelisted_user_ids: []
     # 例如：
     # whitelisted_user_ids:
     # - 76561199570869496@steam

     # 进一步收紧：管理员还必须具备这些具体 RA 权限（留空=只看有没有 RA）
     require_ra_permissions: []
     # 例如：
     # require_ra_permissions:
     # - KickingAndShortTermBanning

     # .cl about 是否对所有人开放
     allow_about_for_everyone: true

     # 被拒绝时提示什么
     deny_message: '你没有权限使用这个测试插件。'

     # 被拒绝时是否记日志
     log_denials: true

  ── 查看当前权限设置 ──────────────────────────────────────────────────

     .cl perms

     会列出谁能用、白名单有谁、你当前是什么身份。


================================================================================
  ★★★ 装了之后必须先解锁，否则它什么都不做 ★★★
================================================================================

  1. 按 Win+R，输入下面这行，回车：

       %APPDATA%\EXILED\Configs\Plugins\awa_cheatlab

  2. 用记事本打开里面的 7777.yml（7777 是你的服务端端口）

  3. 找到这一行，把 false 改成 true：

       i_understand_this_is_a_test_tool: false

  4. 保存，重启服务端

  这是防呆设计：万一这个 DLL 被拷到别人的服务器上，
  对方不手动解锁，它什么都不会做。

  注意这是两道独立的锁：
     第一道 i_understand_this_is_a_test_tool  —— 插件整体开关
     第二道 权限管理                          —— 决定谁能操作
  两道都过了才能用。


================================================================================
  命令一览（游戏内按 ~，前面都要加点）
================================================================================

  ── 开关与信息 ────────────────────────────────────────────────────────

    .cl about      看它是什么（为什么不是外挂）  ★ 唯一对所有人开放的命令
    .cl perms      看当前权限设置和你自己的身份
    .cl on         开启
    .cl off        关闭
    .cl status     看当前是开还是关
    .cl list       列出全部命令

  ── 状态类（可以自己一个人做）────────────────────────────────────────

    .cl items         刷一大堆物品（含 E11 步枪）
                      → 测刷物品检测，正常会被清空背包
    .cl noclip        开启 NoClip（穿墙）
    .cl teleport      瞬移出去 60 米
    .cl fly           垂直飞起来 40 米
    .cl god           开启无敌
    .cl door          把最近的门直接解锁并打开（免卡开门）
    .cl heal          异常治疗（一次回满血）
    .cl spin 60       原地高速旋转
    .cl jitter 60     随机乱转
    .cl all           以上全部依次跑一遍

  ── 射击类（必须有两个玩家）──────────────────────────────────────────

    ★ 游戏对「打自己」有自伤保护，打自己不掉血也不算命中，
      所以必须叫一个朋友进来当靶子。

    ★ 开枪的人手里要有枪：先 .cl items，然后在游戏里切到 E11 步枪。

    .cl aimbot <靶子昵称>           自瞄（默认瞄头，造爆头率异常）
    .cl aimbot <靶子昵称> body      瞄身体（对照用）
    .cl aimbot <靶子昵称> 60        打 60 发
    .cl esp <靶子昵称>              透视痕迹（给靶子套隐身再打他）
    .cl shoot <靶子昵称>            普通开火
    .cl rapidfire <靶子昵称>        真实连发


================================================================================
  做完怎么看结果
================================================================================

    .dsac report

  会列出每个检测器抓到过几个人，还有硬违规数量。


================================================================================
  完整的测试流程（建议照这个走一遍）
================================================================================

     1. 进游戏，按 ~
     2. .cl perms                 先确认自己有权限
     3. .cl on                    开启
     4. .cl items                 刷物品
     5. 等 2 秒，.dsac report      看「可疑物品」有没有亮
        （背包应该被清空，屏幕上会弹提示）

     6. .cl noclip                开 NoClip
     7. 等 2 秒，.dsac report      看「NoClip」有没有亮

     8. .cl spin 60               原地旋转
     9. 等 2 秒，.dsac report      看「朝向异常」有没有亮

    10. 叫朋友进服务器，你切到 E11 步枪
    11. .cl aimbot 朋友昵称        自瞄他
    12. 等 2 秒，.dsac report      看命中率/爆头率

  ★ 触发处置时你会看到嘲讽，全服玩家会看到公告 —— 那说明整条链路通了。

  ★ 测试期间建议把反作弊的 action 设成 Kill（只处死，不封人），
    免得把朋友封了。


================================================================================
  测完记得卸载
================================================================================

  先把服务端关掉，然后删掉这个文件：

      %APPDATA%\EXILED\Plugins\AwaCheatLab.dll

  重启服务端。正式服不要留着它。

  配置文件可以留着（下次装回来设置还在）：
      %APPDATA%\EXILED\Configs\Plugins\awa_cheatlab\


================================================================================
  常见问题
================================================================================

  Q: 输入 .cl on 说我没权限？
  A: 正常。这个插件只对服务器所有者和管理员开放。
     用 .cl perms 看你当前的身份。
     如果你是服务器所有者却被拒了，检查配置里的 allow_server_owner。

  Q: 我是管理员但还是被拒？
  A: 看配置里的 require_ra_permissions —— 如果填了具体权限，
     你还得具备那些权限。 .cl perms 会告诉你缺什么。

  Q: 想让某个普通玩家也能用怎么办？
  A: 把他的 UserID 填进 whitelisted_user_ids。
     不用把 RA 权限给他，只开这一个插件就行。

  Q: .cl 命令报「命令不存在」？
  A: 前面少了一个点。要打 .cl on，不是 cl on。

  Q: 解锁了、配置也对了，还是没反应？
  A: 改配置后必须重启服务端。配置只在启动时读。
