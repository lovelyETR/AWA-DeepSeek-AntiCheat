================================================================================
  AWA 反作弊测试插件          Alpha v1.2
  插件名：AwaCheatLab        命令前缀：.cl
================================================================================

【这是什么】

  服务端插件。用来验证反作弊插件能不能抓到作弊。

  它在服务端制造出「作弊才会产生的状态」，然后你去看反作弊抓到了没有。

  它不是外挂：

    1. 服务端插件，玩家装不了
    2. 装到客户端完全没用
    3. 发给别人也没用，必须在对方服务器上手动解锁才会运行
    4. 就算装上了，也只有服务器所有者 / 管理员 / 白名单能用


================================================================================
  两道锁（都必须过，插件才会工作）
================================================================================

  ── 第一道：解锁 ──────────────────────────────────────────────────────

    1. 按 Win+R，输入这行回车：

         %APPDATA%\EXILED\Configs\Plugins\awa_cheatlab

    2. 用记事本打开里面的 7777.yml（7777 是你的服务端端口）

    3. 把这一行改成 true：

         i_understand_this_is_a_test_tool: true

    4. 保存，重启服务端

    不改这一行，插件什么都不做。

  ── 第二道：权限 ──────────────────────────────────────────────────────

    能用的三类人（满足任一即可）：

        1. 服务器所有者   —— 服务端控制台，或者游戏里的主机
        2. 管理员         —— 有 RemoteAdmin 权限的人
        3. 白名单         —— 配置里点名允许的 UserID

    其他人输入任何 .cl 命令都会看到：

        你没有权限使用这个测试插件。
        它只对服务器所有者和管理员开放。

    并且服务端日志会记一笔，能查到是谁想用。

    唯一例外是 .cl about —— 它只是说明文字，不执行任何操作，
    默认对所有人开放。


================================================================================
  什么能用，什么不能用
================================================================================

  ── ✅ 一个人就能用（状态类）────────────────────────────────────────

    .cl items         刷一大堆物品（含一把 E11 步枪，方便接着做射击测试）
    .cl noclip        开启 NoClip（穿墙）
    .cl teleport      瞬移出去 60 米
    .cl fly           垂直飞起来 40 米
    .cl god           开启无敌
    .cl door          把最近的门直接解锁并打开
    .cl heal          异常治疗（一次回满血）
    .cl spin 60       原地高速旋转 60 次
    .cl jitter 60     随机乱转 60 次
    .cl all           以上全部依次跑一遍

    这些在单人测试服里就能跑，不需要别人。

  ── ⚠️ 必须有第二个玩家（射击类）────────────────────────────────────

    .cl aimbot <靶子昵称>           自瞄，默认瞄头
    .cl aimbot <靶子昵称> body      瞄身体
    .cl aimbot <靶子昵称> 60        打 60 发
    .cl esp <靶子昵称>              给靶子套隐身，然后打他
    .cl shoot <靶子昵称>            普通开火
    .cl rapidfire <靶子昵称>        真实连发

    为什么必须两个人：
      游戏对「打自己」有自伤保护。打自己不掉血，也不算命中，
      反作弊一个数据都收不到。所以必须叫一个朋友进来当靶子。

    开枪的人手里要有枪 —— 任何枪都行，不限型号：
      先 .cl items（它会给你一把 E11 步枪），然后在游戏里手动切到那把枪。
      手上没枪时射击类命令会直接报错。

  ── ⛔ 用不了的（以及为什么）────────────────────────────────────────

    · 打自己            不行。有自伤保护，收不到数据。
    · 对着空气开枪      不行。没有命中事件，反作弊没有东西可判。
    · 单人测射击类      不行。同上，必须有第二个玩家。
    · 让非管理员操作    不行。会被权限门拦住。
    · 没解锁就跑命令    不行。插件整体不工作。
    · 在正式服用        不建议。这个插件是给测试服用的。

  ── 开关与信息 ───────────────────────────────────────────────────────

    .cl about      看这个插件是什么               ★ 对所有人开放
    .cl perms      看权限设置和你自己的身份
    .cl on         开启
    .cl off        关闭
    .cl status     看当前是开还是关
    .cl list       列出全部命令


================================================================================
  权限配置
================================================================================

  配置文件，`%APPDATA%\EXILED\Configs\Plugins\awa_cheatlab\<端口>.yml`：

     # 谁能用
     allow_server_owner: true      服务器所有者
     allow_remote_admin: true      管理员（关掉就只有所有者能用）

     # 额外点名允许的玩家（适合给测试号开权限，不用给他 RA）
     whitelisted_user_ids: []
     # whitelisted_user_ids:
     # - 76561199570869496@steam

     # 管理员还必须具备这些具体 RA 权限（留空 = 只看有没有 RA）
     require_ra_permissions: []
     # require_ra_permissions:
     # - KickingAndShortTermBanning

     # .cl about 是否对所有人开放
     allow_about_for_everyone: true

     # 被拒绝时提示什么
     deny_message: '你没有权限使用这个测试插件。'

     # 被拒绝时是否记日志
     log_denials: true

  查看当前设置：`.cl perms`


================================================================================
  完整测试流程
================================================================================

     1. 进游戏，按 ~
     2. .cl perms                 先确认自己有权限
     3. .cl on                    开启
     4. .cl items                 刷物品
     5. 等 2 秒，.dsac report      看「可疑物品」有没有亮

     6. .cl noclip                开 NoClip
     7. 等 2 秒，.dsac report      看「NoClip」有没有亮

     8. .cl spin 60               原地旋转
     9. 等 2 秒，.dsac report      看「朝向异常」有没有亮

    10. 叫朋友进服务器，你切到那把枪（任何枪都行）
    11. .cl aimbot 朋友昵称        自瞄他
    12. 等 2 秒，.dsac report      看命中率 / 爆头率

  触发处置时你会看到嘲讽，全服玩家会看到公告。


================================================================================
  卸载
================================================================================

  先关服务端，然后删掉：

      %APPDATA%\EXILED\Plugins\AwaCheatLab.dll

  重启服务端。配置文件可以留着。


================================================================================
  常见问题
================================================================================

  Q: 输入 .cl on 说我没权限？
  A: 用 .cl perms 看你当前的身份。
     如果你是服务器所有者却被拒了，检查配置里的 allow_server_owner。

  Q: 我是管理员但还是被拒？
  A: 可能配置里写了 require_ra_permissions，你缺那些权限。
     .cl perms 会告诉你缺什么。

  Q: 想让某个普通玩家也能用？
  A: 把他的 UserID 填进 whitelisted_user_ids，不用给他 RA。

  Q: .cl 命令报「命令不存在」？
  A: 前面少了一个点。要打 .cl on，不是 cl on。

  Q: 解锁了、配置也对了，还是没反应？
  A: 改配置后必须重启服务端。

  Q: 射击类命令说找不到靶子？
  A: 确认朋友已经进服务器了，昵称要写对（支持部分匹配）。

  Q: 射击类命令说不许打自己？
  A: 需要一个别人当靶子，游戏对打自己有保护。
