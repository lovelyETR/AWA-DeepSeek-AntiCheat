================================================================================
                    AWA 反作弊插件整合包        Alpha v1.0
                          安装教程（傻瓜版）
================================================================================

别管文件夹里那些东西是什么，你只需要用最外面那三个按钮。


================================================================================
  第一步：按顺序双击这些按钮
================================================================================

   ① 先装这个-EXILED框架.bat          必须第一个装
   ② 装反作弊插件-公共版.bat          主体，必装
   ③ 装测试插件.bat            ★ 可以不装，但建议装一次测测


   ★★ 要发给别人的话，整个「反作弊插件-公共版【可以发给别人】」文件夹
      加上本教程一起发就行 —— 里面不含任何注入能力。

  双击之后会弹出一个黑窗口，里面显示 [√] 就是成功了。
  窗口最下面写「按回车关闭」，你按一下回车关掉就行。


================================================================================
  第二步：填 API Key（很重要）
================================================================================

  先找到这个文件夹：

     C:\Users\你的用户名\AppData\Roaming\EXILED\Configs\Plugins\deepseek_anticheat

  窍门：按下键盘 Win 键 + R，输入下面这行，回车，就直接打开了：

     %APPDATA%\EXILED\Configs\Plugins\deepseek_anticheat

  里面有文件名叫 7777.yml（7777 是你的服务器端口号）。
  用记事本打开它，找到这一行：

     api_key: ''

  改成（把 sk-xxxxx 换成你自己的 Key）：

     api_key: 'sk-xxxxx'

  Key 去哪里申请？ →  https://platform.deepseek.com

  不填行不行？ → 行。插件会只做本地检测，不联网、不花钱，
                  只是少了一层 AI 复核，准确率低一些。


================================================================================
  第三步：告诉插件你的服务器有什么特色功能（不填对会误报）
================================================================================

  同一个文件（7777.yml）的最上面，有一段 features:，长这样：

     features:
       infinite_stamina: false
       infinite_ammo: false
       cutscene_flight: false
       custom_teleport: false
       abnormal_heal: false
       gives_items: false
       noclip_for_admins: true
       god_mode_for_admins: true

  对照下面这张表改。有就改成 true，没有就保持 false：

     你的服务器有…                        把这一项改成 true      不改会怎样
     ────────────────────────────────────────────────────────────────────
     无限体力 / 加速插件                   infinite_stamina      误报加速外挂
     无限子弹                              infinite_ammo         误报无限弹药
     过场动画 / 通话要玩家上下飞           cutscene_flight       误报飞天
     自定义传送 / 传送门                   custom_teleport       误报瞬移
     异常治疗类技能或道具                  abnormal_heal         误报异常回血
     服务器主动发物品（补给/奖励）         gives_items           误报刷物品，
                                                                 还会清空玩家背包

  最后两项建议保持 true（你自己用管理员 NoClip 不会被当成作弊）：

     noclip_for_admins: true
     god_mode_for_admins: true

  ★ 大部分普通服务器，全部保持 false 就对，不用改。


================================================================================
  第四步：重启服务端
================================================================================

  配置只在服务端启动的时候读一次。
  改完配置文件，必须重启服务端才生效。

  怎么重启？看你平时怎么开的：
     - 用 LocalAdmin 开的 → 关掉再开
     - 用启动脚本开的     → 关掉窗口再双击脚本


================================================================================
  第五步：确认装成功了
================================================================================

  进游戏，按键盘左上角的 ~ 键（Esc 下面那个），打开控制台，
  输入下面这行，然后回车：

     .dsac list

  ★ 注意最前面有一个英文句点「.」，不能少！

  能看到一堆命令列表 = 装成功了。


  如果显示 "Command dsac does not exist!"：
      → 99% 是忘了打那个点。要打 .dsac list，不是 dsac list
      → 那个点是游戏本身的规矩，不是插件的问题


  想看看当前设置对不对，输入：

     .dsac features

  它会列出所有 features 开关的当前状态。


================================================================================
  关于第三个按钮（反作弊测试插件）—— 建议装，但可以不装
================================================================================

  ★ 它是干什么的？

  反作弊插件是「抓作弊的」。但你怎么知道它真的抓得住？

  平时你没法验证 —— 总不能真去找个外挂来试。

  这个测试插件就是干这个的：它能在服务端「制造出作弊才会产生的状态」，
  然后你看反作弊能不能抓到。等于给自己出了套模拟题。

  ★ 它为什么不是外挂？

     它是服务端插件，没有客户端能力：
       - 玩家装不了它（只有服务器管理员能往服务端放 DLL）
       - 装到你自己电脑上完全没用（客户端根本不加载 EXILED 插件）
       - 发给别人也没用（得对方管理员自己装、自己解锁）

     它做的只是「让服务端自己产生作弊状态」，好让检测器有东西可抓。

     游戏里输入 .cl about 可以看到完整说明。

  ★ 可以不装吗？

     可以。不装的话反作弊照常工作，只是一直没被验证过。

     但强烈建议装一次测一下 —— 你会亲眼看到：
       - 检测器到底有没有在工作
       - 嘲讽和全服公告长什么样
       - 刷物品会不会真的被清空背包

     测完就卸载掉（把 %APPDATA%\EXILED\Plugins\AwaCheatLab.dll 删掉，
     重启服务端），正式服就不要留它。

  ★★★ 权限：只有管理员和服务器所有者能用 ★★★

     装好之后不是谁都能用 —— 普通玩家输入任何 .cl 命令都会被拒绝：

         你没有权限使用这个测试插件。
         它只对服务器所有者和管理员开放。

     能用的三类人：
         1. 服务器所有者   —— 服务端控制台，或者游戏里的主机
         2. 管理员         —— 有 RemoteAdmin 权限的人
         3. 白名单         —— 配置里点名允许的 UserID

     唯一例外是 .cl about —— 它只是说明文字，不执行任何注入，
     默认对所有人开放，好让别人能自己确认它不是外挂。

     想调整？打开测试插件的配置文件（下面有路径），这几个开关：

         allow_server_owner: true      服务器所有者（建议保持 true）
         allow_remote_admin: true      管理员（关掉就只有你自己能用）
         whitelisted_user_ids: []      额外点名允许的玩家
         require_ra_permissions: []    管理员还要额外具备的 RA 权限
         allow_about_for_everyone: true

     进游戏输入 .cl perms 可以看当前权限设置和你自己的身份。

  ★★★ 装了之后必须先解锁，否则它拒绝运行 ★★★

     这是为了防呆：万一这个 DLL 被拷到别人的服务器上，
     对方不手动解锁，它什么都不会做。

     解锁方法：
       1. 按 Win+R，输入下面这行回车：
          %APPDATA%\EXILED\Configs\Plugins\awa_cheatlab
       2. 用记事本打开里面的 7777.yml（7777 是你的端口）
       3. 找到这一行，把 false 改成 true：
          i_understand_this_is_a_test_tool: false
       4. 保存，重启服务端


================================================================================
  测试插件的命令（萌新看这里）
================================================================================

  ★ 游戏内输入，前面都要加点「.」，不加点会说命令不存在

  【开关 —— 随时开随时关，不用重启】

     .cl about           看这个插件是什么、为什么不是外挂
     .cl perms           看权限设置和你自己的身份
     .cl on              开启（解锁后还要手动开一次）
     .cl off             关闭
     .cl status          看当前是开还是关
     .cl list            列出全部命令

  【状态类 —— 可以对自己用，不需要别人】

     .cl items           给自己刷一大堆物品（含一把 E11 步枪，方便接着做射击测试）
                         → 测「刷物品检测」，正常会被清空背包

     .cl noclip          开启 NoClip（穿墙）
                         → 测 NoClip 检测

     .cl teleport        瞬移出去 60 米
                         → 测瞬移 / 速度检测

     .cl fly             垂直飞起来 40 米
                         → 测飞天检测

     .cl god             开启无敌
                         → 测「打不死的异常」

     .cl door            把最近的门直接解锁并打开（不用刷卡）
                         → 测免卡开门

     .cl heal            异常治疗（一次回满血）
                         → 测异常回血

     .cl spin 60         原地高速旋转 60 次
                         → 测旋转异常

     .cl jitter 60       随机乱转 60 次
                         → 测抖动异常

     .cl all             以上状态类全部依次跑一遍

  【射击类 —— 必须有两个玩家，一个开枪一个当靶子】

     ★ 为什么必须两个人？
       游戏对「打自己」有自伤保护，打自己不掉血也不算命中，
       反作弊一个数据都收不到。所以要叫上你的朋友。

     ★ 开枪的人手里必须有枪 —— 任何枪都行：
       先 .cl items（会给一把 E11 步枪），然后在游戏里手动切到那把枪。

     .cl aimbot <靶子昵称>           自瞄：每打一枪都重新转向瞄准（默认瞄头）
                                     → 会造出爆头率、命中率异常
     .cl aimbot <靶子昵称> body      同上，但瞄身体（对照用）
     .cl aimbot <靶子昵称> 60        打 60 发

     .cl esp <靶子昵称>              透视痕迹：给靶子套隐身然后打他
                                     → 测「命中隐身目标」检测

     .cl shoot <靶子昵称>            普通开火（不转向瞄准）
     .cl rapidfire <靶子昵称>        真实连发，测射速异常

  【做完怎么看结果】

     .dsac report

     会列出每个检测器抓到过几个人，还有硬违规数量。

--------------------------------------------------------------------------------
  一、反作弊插件 dsac（别名 deepseekanticheat）
--------------------------------------------------------------------------------

  ── 看检测结果 ──────────────────────────────────────────────

    .dsac report          检测器战果汇总：每个检测器抓到过几个人
    .dsac stats           当前跟踪的所有玩家统计与评分
    .dsac panel           开关右上角实时 HUD 面板（嫌挡视线就再打一次关掉）
    .dsac panel preview   面板内容直接打印在控制台（不下发 HUD）
    .dsac panel <玩家名>  给指定玩家开面板
    .dsac reliability     12 项检测能力的可靠性对照表
                          里面会写明哪些服务端根本检测不了（比如透视）

  ── 白名单 ──────────────────────────────────────────────────

    .dsac whitelist                       查看完整白名单
    .dsac whitelist add <UserID或昵称>     加入（立即生效，不用重启）
    .dsac whitelist remove <UserID>        移出
    .dsac whitelist addrole <角色名>       加入角色白名单
    .dsac whitelist removerole <角色名>    移出
    .dsac whitelist clear                  清空

    ★ 白名单是干什么的？
      名单里的玩家/角色【完全不参与检测】——
      不是「检测到了但不处置」，而是压根不进检测流程。

      什么时候用它：
        - 服主自己的号，或者已知的特殊玩家
        - 某些角色天生数据异常（比如 SCP-049、SCP-096），
          不该按普通玩家的标准判

    ★ 可以填在线玩家的昵称，会自动解析成 UserID：
        .dsac whitelist add 某某某

    ★ 命令加的立即生效并写回配置文件，不用重启。
      手动改配置文件加的才需要重启。

  ── 累犯封禁台账 ────────────────────────────────────────────

    .dsac bans                  看谁被封过几次（决定下次封多久）
    .dsac bans reset <UserID>   把某人的次数清零（封错了要撤销时用）

  ── 跟踪与取证 ──────────────────────────────────────────────

    .dsac follow <玩家>          开始跟踪，他的所有事件单独记录
    .dsac unfollow <玩家>        停止跟踪
    .dsac replay <玩家> [条数]   输出行为时间线（何时开枪、命中谁、位置怎么变）
    .dsac evidence               列出已落盘的证据文件

    证据落在：
      %APPDATA%\EXILED\Configs\Plugins\deepseek_anticheat\evidence\

  ── 服务器特性配置 ──────────────────────────────────────────

    .dsac features        看 features 白名单的当前状态

    ★ 这一项很重要：你的服务器如果开了无限体力、无限子弹、
      过场飞行、主动发物品等等，必须在配置文件里打开对应开关，
      否则那些功能会被当成作弊，导致误报。

  ── 自检与模拟 ──────────────────────────────────────────────

    .dsac selftest        逐项自检（合成数据 → 评分 → 理由）
    .dsac list            列出全部模拟场景
    .dsac sim <场景ID>    跑本地评分（秒回，不联网、不花钱）
    .dsac ai <场景ID>     走完整 AI 链路，结果广播给管理员

    ★ <场景ID> 是参数，不是命令。
      直接敲 cheat_aimbot 会报「命令不存在」。
      正确写法：.dsac sim cheat_aimbot

    常用场景 ID：
      legit_newbie / legit_average / legit_veteran / legit_scp096
      edge_low_sample
      cheat_aimbot / cheat_triggerbot / cheat_rapidfire / cheat_damage
      cheat_killfarm / cheat_noclip / cheat_speed / cheat_teleport
      cheat_fly / cheat_invisible_hit / cheat_infinite_ammo
      cheat_reaction / cheat_full

  ── 真实性钻取（本整合包不带此功能）──────────────────────────

    .dsac drill list      列出全部钻取项
    .dsac drill <id>      对你自己执行一次
    .dsac drill <id> <玩家>   对指定玩家执行

    钻取项：
      noclip      真实开启 NoClip
      teleport    真实瞬移
      vertical    真实垂直飞天
      items       真实刷物品
      heal        真实异常治疗
      shoot       服务端驱动真实开火
      rapidfire   真实连发

    ★ 本整合包里的反作弊插件【没有】这个命令 ——
      它不含任何注入能力，这是有意为之。
      你想在自己服务器上用这个功能，需要另外装「官方安装版」。

  常见问题
================================================================================

  Q: 双击按钮，黑窗口一闪就没了？
  A: 杀毒软件拦了。把这个文件夹加到杀毒软件白名单，再双击。

  Q: 提示「找不到 EXILED 目录」？
  A: 你还没装框架。先双击 ①。

  Q: 改了配置没生效？
  A: 重启服务端。配置只在启动时读一次。

  Q: 反作弊误判我自己人？
  A: 第一步先输入 .dsac features 检查 features 有没有填对。
     还不行就把配置文件里的 action 改成 Alert，这样就只通报、不处置任何人。

  Q: 反作弊会不会乱封人？
  A: 默认是「从轻到重」：前两次只处死（不封），第三次才开始封 3 天。
     想更保险就改成 action: Alert。

  Q: 在哪里看检测记录？
  A: 服务端那个黑窗口里搜 AWA。
     有硬违规时会自动存证据到这个文件夹：
     %APPDATA%\EXILED\Configs\Plugins\deepseek_anticheat\evidence

  Q: 我把插件装到我自己电脑的游戏目录里了，怎么没反应？
  A: EXILED 插件只在服务端加载。装客户端没用，客户端根本不读它。

  Q: 配置文件在哪里？
  A: 按 Win+R，输入下面这行回车：
     %APPDATA%\EXILED\Configs\Plugins
