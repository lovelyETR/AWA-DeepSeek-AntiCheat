# 配置说明

配置文件位置：

```
%APPDATA%\EXILED\Configs\Plugins\deepseek_anticheat\<端口>.yml
```

`<端口>` 是你的服务端端口（默认 `7777`）。
**文件名就是端口号** —— 端口不对，EXILED 会重新生成一份默认的，你改的那个就不生效。

`%APPDATA%` 一般是 `C:\Users\你的用户名\AppData\Roaming`。

> **改完必须重启服务端**，配置只在启动时读一次。
>
> 例外：白名单可以用 `.dsac whitelist` 命令改，那样立即生效并写回文件。

## 一、必做的两件事

### ① 填 API Key

```yaml
api_key: 'sk-你的Key'
```

到 https://platform.deepseek.com 申请。

**不填也能用** —— 只跑本地启发式检测，完全不联网、零成本，只是少一层 AI 复核。

### ② 按自己服务器的情况改 `features`

**这一节不改对会导致误报。** 你的服务器开了下面任何功能，就必须把对应项改成 `true`：

| 你的服务器有 | 改成 true | 不改会误报成 |
|---|---|---|
| 无限体力 / 加速插件 | `infinite_stamina` | 移速异常 |
| 无限子弹 | `infinite_ammo` | 无限弹药 |
| 过场 / 通话需要玩家上下飞 | `cutscene_flight` | 飞天 |
| 自定义传送 / 传送门 | `custom_teleport` | 瞬移 |
| 异常治疗类技能或道具 | `abnormal_heal` | 异常回血 |
| 服务器主动给玩家发物品 | `gives_items` | 刷物品（**会清空玩家背包**）|

```yaml
features:
  infinite_stamina: false
  infinite_ammo: false
  cutscene_flight: false
  custom_teleport: false
  abnormal_heal: false
  gives_items: false

  # 管理员用 NoClip / 上帝模式不算作弊（建议保持 true）
  noclip_for_admins: true
  god_mode_for_admins: true

  # 不想整个关掉，只想放宽一点？用倍率
  speed_tolerance_multiplier: 1        # 移速上限乘以这个数
  vertical_tolerance_multiplier: 1     # 垂直速度上限乘以这个数
  item_spam_tolerance_multiplier: 1    # 刷物品门槛乘以这个数

  # 完全跳过检测的玩家（形如 76561199570869496@steam）
  whitelisted_user_ids: []

  # 完全跳过检测的角色（名字包含即匹配，不区分大小写）
  whitelisted_roles: []
```

**大部分普通服务器，全部保持 `false` 就是对的。**

## 二、AI 复核

```yaml
enable_ai_review: true
api_base_url: 'https://api.deepseek.com'
model: 'deepseek-chat'
use_json_response_format: true
timeout_seconds: 20
max_tokens: 400
```

| 项 | 说明 |
|---|---|
| `enable_ai_review` | 关掉就只跑本地检测 |
| `api_base_url` | 换成走 ai-proxy 的话填 `http://127.0.0.1:8787/v1` |
| `model` | `deepseek-chat`（快、便宜）或 `deepseek-reasoner`（更准、更贵）|
| `use_json_response_format` | 部分本地框架（Ollama 等）不支持，会直接报错，这时改 `false` |
| `timeout_seconds` | 本地模型慢的话调大 |
| `include_player_identity` | 是否把昵称/UserID 发给 AI。默认 `false`（不泄露玩家身份）|

### 调用预算

```yaml
max_api_calls_per_player_per_round: 2     # 每人每局最多复核几次
max_api_calls_per_round: 15               # 全服每局最多几次
cooldown_seconds: 120                     # 同一玩家的复核间隔
```

**这几项是防刷爆余额的关键。** 建议保持默认或更小。

## 三、判定阈值与处置

```yaml
local_score_to_report: 35      # 本地分超过这个才送 AI 复核
verdict_threshold: 80          # AI 嫌疑度超过这个才处置
hard_violation_threshold: 50   # 有硬违规时用这个更低的门槛
action: Ban                    # Alert / Kick / Ban / Kill
```

**`action` 的含义**：

| 值 | 行为 |
|---|---|
| `Alert` | **只通报，什么都不做** ← 建议先用这个跑一段时间 |
| `Kick` | 踢出服务器 |
| `Kill` | 当场处死（不封禁）|
| `Ban` | 走下面的递进阶梯 |

### 递进封禁阶梯

```yaml
use_progressive_bans: true
punishment_ladder:
- kill      # 第 1 次：处死
- kill      # 第 2 次：处死
- 3         # 第 3 次：封 3 天
- 7         # 第 4 次：封 7 天
- 90        # 第 5 次：封 90 天
- 365       # 第 6 次：封 365 天
- perm      # 第 7 次起：永久
```

每一档可以填：

| 写法 | 含义 |
|---|---|
| `kill` / `处死` | 当场处死，不封禁 |
| 数字（如 `7`）| 封 N 天 |
| `perm` / `permanent` / `永久` / `0` | 永久封禁 |

超出阶梯长度就一直用最后一档。

**关掉阶梯**（`use_progressive_bans: false`）就用固定天数：

```yaml
ban_duration_days: 7
```

> ## ⚠️ 强烈建议
>
> **先把 `action` 设成 `Alert` 跑一两个星期**，观察日志里 AI 的判定质量，
> 确认没有误判之后再开启处置。
>
> 为什么会误判：内置的 `legit_veteran`（合法高玩）场景能打到 75 分，
> 而默认阈值是 80 —— 只差 5 分。技术进步一点就可能越线。
>
> 封错了要撤销：`.dsac bans reset <玩家UserID>`

### 封禁台账

次数记在：

```
%APPDATA%\EXILED\Configs\Plugins\deepseek_anticheat\bans.json
```

用 `.dsac bans` 查看，`.dsac bans reset <UserID>` 清零。

## 四、通知文案

```yaml
taunt_message: '叮检测到宿主开挂已开启超级大肥鱼反外挂系统'
taunt_duration: 12
announce_punishment_to_all: true
punishment_announcement: '检测到作弊者{player}'
punishment_announcement_duration: 10
announce_to_admins: true
```

- **嘲讽**（`taunt_message`）发给被处置的人
- **全服公告**（`punishment_announcement`）发给所有人，`{player}` 会替换成昵称
- **管理员通报**（`announce_to_admins`）走管理员频道，含 AI 的完整理由

## 五、检测阈值微调

**不建议一开始就动这些。** 先用默认值跑，看 `.dsac report` 的实际数据再调。

### 射击

```yaml
headshot_ratio_threshold: 0.75            # 爆头率
accuracy_threshold: 0.80                  # 命中率
kills_per_minute_threshold: 5             # 每分钟击杀
long_range_headshot_distance: 45          # 多远算「远距离」
long_range_headshot_ratio_threshold: 0.40
max_reasonable_damage: 120                # 单发伤害上限
max_reasonable_shots_per_second: 20       # 射速上限
max_reasonable_shots_per_magazine: 60     # 一个弹匣打几发
human_reaction_floor_ms: 150              # 人类反应极限
```

### 移动

```yaml
enable_movement_detection: true
max_reasonable_speed: 12                  # 水平速度上限（米/秒）
max_reasonable_vertical_speed: 10         # 垂直速度上限
teleport_distance: 25                     # 一次移动超过这个算瞬移
movement_sample_interval: 0.3             # 采样间隔（秒）
max_reasonable_yaw_speed: 600             # 转身速度上限（度/秒）
spin_streak_needed: 8                     # 连续几次超速才算旋转异常
jitter_yaw_speed: 500
jitter_streak_needed: 8
```

### 其他

```yaml
max_reasonable_heal: 200                  # 单次治疗量上限
detect_invisible_target_hits: true        # 命中 SCP-268 隐身目标
detect_noclip: true
min_samples: 25                           # 样本不足时不做统计判定
item_spam_window_seconds: 10              # 刷物品：统计窗口
item_spam_threshold: 8                    # 窗口内拿到这么多件算刷
clear_inventory_on_item_spam: true
```

## 七、用 ai-proxy 保护 Key（推荐）

如果你要把配置分享给别人，或者不想让 Key 散落在各处，
用 [ai-proxy](https://github.com/lovelyETR/ai-proxy) 把 Key 收在一处：

```yaml
api_base_url: 'http://127.0.0.1:8787/v1'
api_key: 'my-token-1'          # 令牌，不是真 Key
```

好处：

- 配置里只有可随时吊销的令牌，泄露了删掉就行，不用换 Key
- 统一限流与每日配额，插件写错也刷不爆余额
- 换 Key / 换模型只改代理一处

## 八、自用版额外项

自用版（`-p:AwaEdition=Private`）默认处置是 `Kill`、且含 `.dsac drill` 测试钻取命令。

**公共版没有这些** —— 公共版不含任何注入能力，`drill` 命令会直接回复「本版本不包含真实性钻取功能」。
