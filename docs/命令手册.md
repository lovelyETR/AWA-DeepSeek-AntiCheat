# 命令手册 —— AWA 反作弊插件 & 测试插件

服务端装了两套命令：

| 命令 | 来自 | 作用 |
|---|---|---|
| **`dsac`** | DeepSeekAntiCheat.dll（反作弊）| 查看检测结果、测试、取证 |
| **`cl`** | AwaCheatLab.dll（测试工具）| 制造作弊状态，验证检测器 |

**在游戏内按 `~` 打开控制台输入。**

> ### ⚠️ 重要：游戏内输入必须加 `.` 前缀
>
> | 在哪输入 | 怎么写 | 例子 |
> |---|---|---|
> | **游戏内按 `~`** | **必须加 `.`** | `.dsac list` |
> | **服务器黑窗口** | 不加前缀 | `dsac list` |
>
> 不加点会被当成客户端本地命令，回报 `Command dsac does not exist!`。
> 这和插件无关 —— 是游戏本身的分发规则。
>
> **底层原理**（读游戏 IL 得到的）：
> | 输入形式 | 去哪 | 由谁处理 |
> |---|---|---|
> | `.cmd` | 发到服务端 | `QueryProcessor.DotCommandHandler` |
> | `cmd`（无点） | 客户端本地 | 客户端命令表 |
> | 服务器黑窗口直接敲 | 服务端本地 | `GameCore.Console.ConsoleCommandHandler` |
>
> 所以插件必须同时标 `RemoteAdminCommandHandler` / `ClientCommandHandler` /
> `GameConsoleCommandHandler` 三个 handler —— EXILED 的注册是 if/else-if 链，
> 只标一个的话，另外两个入口都找不到命令。

# 一、`dsac` —— 反作弊插件

别名：`deepseekanticheat`

## 1. 看数据

| 命令 | 作用 |
|---|---|
| `dsac stats` | 当前跟踪的所有玩家统计与评分 |
| `dsac report` | **检测器战果汇总** —— 每个检测器抓到过几个人 |
| `dsac panel` | 开关右上角实时 HUD 面板（黑白+蓝配色）|
| `dsac panel preview` | 面板内容直接打印在控制台（不下发 HUD，用来确认渲染）|
| `dsac panel <玩家名>` | 给指定玩家开面板 |
| `dsac reliability` | 12 项检测能力的可靠性对照表 |

## 2. 跟踪与取证

| 命令 | 作用 |
|---|---|
| `dsac follow <玩家>` | 开始跟踪，他的所有事件单独记录 |
| `dsac unfollow <玩家>` | 停止跟踪 |
| `dsac replay <玩家> [条数]` | 输出行为时间线（何时开枪、命中谁、位置怎么变），默认 40 条 |
| `dsac evidence` | 列出已落盘的证据文件 |

证据落在：
```
%AppData%\EXILED\Configs\Plugins\deepseek_anticheat\evidence\
```
每次判定成立写一个 JSON，含本地评分明细 + AI 判定理由 + 完整时间线。

## 3. 自检

| 命令 | 作用 |
|---|---|
| `dsac selftest` | 逐项自检（合成数据 → 评分 → 理由），验证评分链路 |
| `dsac list` | 列出全部模拟场景 |
| `dsac sim <场景ID>` | 跑本地评分，秒回，**不联网** |
| `dsac ai <场景ID>` | 走完整 AI 链路，结果广播给管理员 |

> **`<场景ID>` 是参数，不是命令。** 直接敲 `cheat_aimbot` 会报 `Command cheat_aimbot does not exist!`
> 正确写法：`dsac sim cheat_aimbot` 或 `dsac ai cheat_aimbot`

# 二、`cl` —— 测试插件（CheatLab）

别名：`awalab`

**它不是外挂** —— 它是服务端插件，没有客户端能力。输入 `.cl about` 看完整说明。

## 开关（随便开随便关，不用重启）

| 命令 | 作用 |
|---|---|
| `.cl on` | 开启 |
| `.cl off` | 关闭 |
| `.cl status` | 看当前状态 |
| `.cl about` | 完整说明 |
| `.cl list` | 列出全部命令 |

**首次使用要先解锁**（配置里 `i_understand_this_is_a_test_tool` 改成 `true` 并重启），
之后就能用 `.cl on` / `.cl off` 随时切换。

## 注入

| 命令 | 做什么 | 对应检测器 |
|---|---|---|
| `.cl shoot [玩家] [发数]` | **服务端驱动真实开火** | 命中率 / 伤害 / 射速 |
| `.cl rapidfire [玩家]` | 真实连发（默认 40 发）| 射速异常 |
| `.cl noclip [玩家]` | 开启 NoClip 状态位 | NoClip |
| `.cl teleport [玩家]` | 瞬移 60 米 + 抬升 25 米 | 瞬移 / 速度异常 |
| `.cl fly [玩家]` | 垂直抬升 40 米 | 飞天 / 悬浮 |
| `.cl items [玩家]` | 刷 14 件物品（含一把 E11 方便接着测）| 可疑物品获取 |
| `.cl heal [玩家]` | 注入 900 点治疗 | 异常回血 |
| `.cl all [玩家]` | 依次跑一遍上面几项 | 全部 |

`[玩家]` 省略时以你自己为目标。`cl all` 会跳过射击类（需要有枪）。

# 三、标准测试流程

## 快速验证（5 分钟）

```
1. 进游戏，按 ~
2. .dsac panel preview        确认面板渲染正常
3. .cl on                     开启测试插件
4. .dsac drill noclip         制造 NoClip 条件
5. 等 2 秒
6. .dsac report               看 NoClip 检测器有没有亮
```

`dsac report` 输出示例：

```
检测器战果（本局累计）
  NoClip（状态位）        ✅ 1 人
  移动异常（位置采样）      — 未触发
  命中隐身目标            — 未触发
  ...
触发明细: 你的昵称(NoClip)
```

**亮了 = 事件挂钩真的通了** —— 这是最关键的一步验证。

## 完整验证（每项都过一遍）

```
.cl on
.dsac drill noclip      →  .dsac report
.dsac drill teleport    →  .dsac report
.dsac drill vertical    →  .dsac report
.dsac drill items       →  .dsac report
.dsac drill heal        →  .dsac report
.cl items               →  游戏里切到那把枪（任何枪都行）
.cl shoot               →  .dsac report
.cl rapidfire           →  .dsac report
```

## 验证 AI 链路

```
.dsac ai cheat_aimbot      游戏内跑完整 AI 链路，结果广播给管理员
```

或离线测：

```
桌面\SCP反作弊插件\模拟器\运行AI测试.bat
```

# 四、常见问题

**`Command .dsac does not exist!`**
→ 插件没加载或命令没注册。看服务端日志里有没有 AWA 横幅和「命令已注册」。

**`dsac panel` 没反应**
→ 先试 `dsac panel preview`。preview 有内容说明渲染没问题，是 HUD 下发的问题。
→ 也可以显式指定：`dsac panel 你的昵称`

**`dsac drill` 执行了但 `report` 里没亮**
→ 事件挂钩有问题。看日志里 `[AWA drill]` 那几行。

**`cl` 命令拒绝执行**
→ 安全锁没解除。改配置 `i_understand_this_is_a_test_tool: true` 并**重启**。
→ 或者运行时开关关着，执行 `cl on`。

**`cl shoot` 说"手上没有枪"**
→ 先 `cl items`，然后在游戏里**手动切到那把枪**（任何枪都行）。

**改了配置不生效**
→ EXILED 只在启动时读配置，**必须重启服务端**。

# 白名单（`.dsac whitelist`）

白名单里的玩家 / 角色**完全不参与检测** —— 不是「检测到了不处置」，而是压根不进检测流程。

| 命令 | 作用 |
|---|---|
| `.dsac whitelist` | 查看完整白名单（含在线玩家昵称）|
| `.dsac whitelist add <UserID或昵称>` | 加入（**立即生效，不用重启**）|
| `.dsac whitelist remove <UserID>` | 移出 |
| `.dsac whitelist addrole <角色名>` | 加入角色白名单 |
| `.dsac whitelist removerole <角色名>` | 移出 |
| `.dsac whitelist clear` | 清空 |

**可以填在线玩家的昵称**，会自动解析成 UserID：

```
.dsac whitelist add 某某某
.dsac whitelist add 76561199570869496@steam
```

**什么时候用它**：
- 服主自己的号、已知的特殊玩家
- 某些角色天生数据异常（SCP-049、SCP-096），不该按普通玩家标准判

**命令加的立即生效并写回配置文件** ✓ 只改 `features` 段那两行 ✓ 不碰你的 API Key ✓
**手动改配置文件加的**才需要重启 ✓

# 完整的 `.cl` 命令表（测试插件）

## 开关

| 命令 | 作用 |

| `.cl on` / `.cl off` | 开启 / 关闭（不用重启）|
| `.cl status` | 看当前状态 |
| `.cl list` | 列出全部命令 |

## 状态类（可以自己一个人做）

| 命令 | 作用 |
|---|---|
| `.cl items` | 刷物品（含一把 E11，任何枪都行）→ 测刷物品检测 |

| `.cl door` | 免卡开门 |
| `.cl heal` | 异常治疗 |
| `.cl spin 60` | 原地高速旋转 |
| `.cl jitter 60` | 随机乱转 |
| `.cl all` | 以上全部依次跑一遍 |

## 射击类（必须两个玩家）

> 游戏对「打自己」有自伤保护，打自己不掉血也不算命中，反作弊收不到数据。
